# ElectroShop
Website e-commerce barang elektronik menggunakan HTML, CSS, dan JavaScript.

## Fitur
- Home
- Produk dan pencarian
- Filter kategori
- Sorting harga
- Detail produk
- Keranjang belanja
- Quantity +/-
- Hapus produk
- localStorage
- Simulasi checkout
- Halaman kategori, tentang, dan kontak
- Responsive desktop/tablet/mobile

## Menjalankan
Buka `index.html` di browser atau gunakan Live Server di VS Code.

Catatan: checkout dan formulir kontak masih berupa simulasi front-end. Produk menggunakan gambar SVG placeholder agar project langsung bisa dijalankan tanpa mencari gambar tambahan.
